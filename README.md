# 1. Why is timely delivery crucial in software project management, and how can project managers ensure deadlines are met?
## Timely delivery is crucial  because it ensures:
### 1. The project does not go over budget 
### 2. The project does not take too long 
### 3. The project does not become too chaotic 
## Project managers should plan accordingly to ensure they meet deadlines.

# 2. How does effective cost control contribute to the success of a software project? What strategies can be used to prevent budget overruns?
## Effective cost control helps with:
### Keeping the project within the budget
### Allows for better planning
### Builds confidence with the stakeholders

## To prevent budget overruns:
### Create a realistic budget
### Use project management tools
### Forecast and review regularly
